\section{Evaluation Methodology}\label{sec:method}

Let $T$ be the evaluated tests, $A\subseteq T$ the accepted ones, and for $t\in T$ let $D(t)$ be its targeted smells (the smells labelled in~\cite{utrefactor}
that the detector in use confirms) and $D'(t)$ the smells still reported in its refactored methods. Rates are percentages; the accepted-losing-mutants rate carries a Wilson 95\% interval.

\textbf{Accepted rate} $=|A|/|T|$. For \textsf{b1}, \textsf{b2} and \textsf{s3} a test is accepted only if the refactoring is statically sane (no dropped or empty test), compiles, passes, and removes the targeted smells;
with G1 on it must also preserve the kill-set. \textsf{single}, \textsf{b0} and \textsf{b0replay} follow~\cite{utrefactor}: accepted if the output compiles and passes (the kill-set is only measured). \textbf{Compile rate} and \textbf{pass rate} are the share of tests whose \emph{last} verification report compiled, respectively passed.

\textbf{Smell reduction} has three definitions. Rule~i (tsDetect, as in~\cite{utrefactor}): $\sum_t|D(t)\setminus D'_{ts}(t)|\,/\,\sum_t|D(t)|$ over all tests; we also report it over accepted tests only.
Rule~ii (strict): a smell counts as removed only if both tsDetect and JNose no longer report it. Rule~iii (manual) is defined in \texttt{labelling\_guide.md}: two labellers judge a 100-test sample independently and we would report Cohen's $\kappa$. \textbf{[TODO state ``not performed'' if no second labeller is available.]}

\textbf{Behaviour preservation.} For test $t$ let $K(t)$ be the set of PIT mutants killed by $t$, from the full mutation matrix. The original's $K(t)$ is computed on the unmodified class
before the patch is written. A refactoring that yields tests $t'_1..t'_m$ preserves behaviour if $K(t)\subseteq\bigcup_i K(t'_i)$.
\textbf{Accepted-losing-mutants rate} is the share of accepted tests violating this; \textbf{accepted-and-safe rate} is the share of $T$ that is accepted and preserves $K$.
Tests with an empty baseline $K(t)$ are counted as \emph{unknown}, not as preserved.

\textbf{Efficiency and reliability.} Total tokens per test (prompt plus completion; the split is not logged), tokens per accepted test, wall-clock latency per test (includes rate-limit waits), tool calls and retries (reported as totals and per-test means), and
\textbf{recovery rate} $=$ accepted tests among those that needed at least one retry. Cost is \$0 on the free tier; we report tokens instead.

\textbf{Comparison protocol.} Every system runs the same test-split tests with seeds 1--3; we report mean $\pm$ sd over seeds. Paired comparisons between systems on the same tests use the exact McNemar test (binary outcomes) and the Wilcoxon
signed-rank test (continuous), with Holm correction across the comparisons in a table and bootstrap confidence intervals for differences.
\textbf{Metric-definition differences from~\cite{utrefactor}:} (i)~our evaluation set has 484 tests (the replication package's reports cover 492 and Table~2 of~\cite{utrefactor} states 593), because the paper does not name its project commits and we pin the commits that contain most of its inputs verbatim; (ii)~we accept an output only if it compiles, passes, removes the targeted smell and (G1) kills every mutant the original killed, whereas rule~i alone credits any output that no longer shows the smell; (iii)~smells are detected per test method; (iv)~Gson is built with its own dependencies. Replaying the published outputs through our verifier (\texttt{b0replay}) matches the paper on Commons-cli (86.4\% vs 86\%) but not on Gson (58.4\% vs 89\%) or Jsoup (53.5\% vs 91\%); we report these as measured with our counting, not as a reproduction of the paper's figures (\texttt{docs/results\_phase1.md}).
